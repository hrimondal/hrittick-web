## Run Locally

**Prerequisites:**  Node.js

Clone:
```sh-session
git clone https://github.com/hrittm/hrittick-web.git
cd hrittick-web
```


Install dependencies:
```sh-session
npm install
```

Run the app:
```sh-session
npm run dev
```
